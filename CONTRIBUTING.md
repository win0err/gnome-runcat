# Contributing to RunCat

Thank you for your interest in contributing!

- **RunCat is intentionally minimalistic:** a running cat and a CPU percentage,
  nothing more. Feature requests and pull requests adding new settings,
  indicators, graphs, or sensors are unlikely to be accepted — see the
  [Philosophy section](README.md#philosophy) of the README.
- **Follow the code style adopted in the project.** All checks in your pull
  request — lint, type checks, and up-to-date translation files — must pass
  before submitting it for review. Run `npm run test` and `make translations`
  locally. See the
  [useful commands for developers](README.md#useful-commands-for-developers)
  section of the README.
- **Please don't submit AI-generated contributions.** Kindly avoid opening
  pull requests with code, documentation, or translations written by AI
  (LLMs).
- **New translations are welcome,** but please be prepared to maintain your
  translation in future versions of the extension. See the
  [Translations section](README.md#translations) of the README for the workflow.
